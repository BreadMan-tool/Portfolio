# 자기소개서 초안

## 범용 자기소개서

고등학생 때부터 게임 개발에 관심이 많아 게임제작과와 컴퓨터정보학과를 거치며 개발자로서의 방향을 찾아왔습니다. 게임 개발 동아리, 웹 개발 인턴십, AI 연구실 학부연구생, 블록체인 부트캠프 등 여러 경험을 해보며 제가 가장 오래 몰입할 수 있는 분야가 무엇인지 확인했고, 결국 게임 클라이언트 개발이 제가 가진 역량을 가장 적극적으로 발휘할 수 있는 분야라는 확신을 갖게 되었습니다.

게임 개발을 본격적으로 학습하던 시기에는 매일 긴 시간을 투자해 Unity와 C# 기반 프로젝트를 만들었습니다. 팀 프로젝트에서는 블록체인 기반 3D RPG 게임과 2D 로그라이크 게임을 제작했고, 기획과 구현을 조율하며 팀원들과 함께 결과물을 완성했습니다. 이 과정에서 협업의 중요성도 크게 배웠습니다. 한 프로젝트에서는 제가 너무 많은 개발을 직접 맡으려다 일정과 완성도 모두에 부담이 생긴 경험이 있었습니다. 이후 인턴십과 팀 프로젝트에서는 각 포지션의 역할을 명확히 나누고, 일정과 구현 범위를 함께 조율하며 프로젝트를 마무리하는 방식으로 개선했습니다.

ActionFit에서는 Unity 클라이언트 개발자로 근무하며 실제 라이브 모바일 게임의 기능 출시와 운영을 경험했습니다. 빠지냥은 코어 게임만 있던 프로젝트를 인수해 Lucky Pass를 제작한 것이 첫 주요 작업이었고, 이후 게임플레이 기믹, 리더보드, 경쟁 콘텐츠, SDK/분석 이벤트, IAP/광고, 클라우드 세이브, 리소스 최적화, Crashlytics 기반 안정성 대응까지 담당했습니다. 처음에는 코드베이스에 익숙해지기 위해 빠른 기능 구현에 집중했고, 콘텐츠가 늘어난 뒤에는 Content Scheduler, Resource Optimizer, 플랫폼별 GPGS/Game Center 클라우드 세이브처럼 반복 작업을 줄이는 구조를 만들었습니다.

장난EZ렁에서는 다른 작업자가 진행하던 로비 코드를 인수해 프로젝트 컨벤션에 맞게 정리했습니다. 특히 VContainer 구조를 학습하며 상점 상품 UI, ScriptableObject 상품 데이터, 튜토리얼, Red Dot, 월간 패스, 신화 상자 기능을 서비스, ViewModel, 공통 UI 컴포넌트 흐름으로 재배치했습니다. 기존 동작을 유지하면서도 이후 기능을 같은 패턴으로 확장할 수 있게 만드는 것이 핵심이었습니다. 깡깡냥에서는 프로젝트 생성부터 클라이언트 구조, UI/HUD, 데이터 테이블, 상점/IAP, 투사체/VFX 시스템을 직접 구축하며, 빠지냥에서 반복적으로 만들었던 기능을 Breadmore Core 기반 구조로 발전시켰습니다.

저는 새로운 코드베이스나 익숙하지 않은 SDK를 만났을 때도 문서와 로그, 기존 코드 흐름을 따라가며 끝까지 이해하려고 합니다. 회사에서 사수 없이 1인 개발에 가까운 환경을 경험하면서 AI를 코드 탐색, SDK 문서 해석, 버그 가설 정리, UI 연출 검토에 적극적으로 활용했고, 모르는 부분을 빠르게 학습해 실제 기능으로 연결하는 방식을 익혔습니다. Firebase, GameAnalytics, Singular 같은 외부 SDK를 붙이고, Crashlytics 지표를 보며 crash-free users 95% 이상을 목표로 안정성을 관리한 경험은 기능 구현뿐 아니라 출시 이후의 품질까지 책임지는 개발자로 성장하는 계기가 되었습니다.

앞으로도 저는 단순히 기능을 빠르게 만드는 데서 끝나지 않고, 라이브 환경에서 오래 유지될 수 있는 구조와 사용자가 안정적으로 경험할 수 있는 클라이언트를 만드는 개발자가 되고 싶습니다. 기존 프로젝트를 인수해 기능을 확장한 경험, 다른 작업자의 코드를 컨벤션에 맞춰 정리한 경험, 새 프로젝트의 기반 구조를 직접 만든 경험을 바탕으로 팀에 빠르게 적응하고 신뢰받는 Unity 클라이언트 개발자로 기여하겠습니다.
