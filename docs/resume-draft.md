# 이력서 문구 초안

## 한 줄 소개

Unity 클라이언트 개발자로 라이브 모바일 게임의 기능 출시, UI, SDK 연동, 분석 이벤트, IAP/광고, 클라우드 세이브, 안정성 대응과 신규 프로젝트 기반 구조 설계를 경험했습니다.

## 경력 요약

ActionFit에서 Unity 클라이언트 개발자로 근무하며 라이브 모바일 게임의 시즌패스, 경쟁 콘텐츠, 리더보드, 상점/IAP, 광고, 분석 이벤트, 외부 SDK, 플랫폼별 클라우드 세이브, UI 연출과 안정성 대응을 담당했습니다. 기존 코드베이스를 인수한 뒤 기능 확장과 리팩토링을 병행했고, 신규 프로젝트에서는 Breadmore Core 기반 클라이언트 구조를 직접 설계했습니다.

## 경력 사항

### ActionFit

Unity Client Developer | 2025.07 - Present

- 라이브 모바일 게임 빠지냥의 Lucky Pass, 게임플레이 기믹, 경쟁 콘텐츠, 리더보드, SDK/분석 이벤트, IAP/광고, Crashlytics 기반 안정성 대응을 담당했습니다.
- 코어 게임만 있던 빠지냥 프로젝트를 인수한 뒤 시즌패스, 콘텐츠 스케줄러, 플랫폼별 GPGS/Game Center 클라우드 세이브, 리소스 최적화 도구를 구현하며 라이브 운영 구조를 확장했습니다.
- 장난EZ렁 로비 시스템을 인수해 VContainer 컨벤션에 맞춰 상점 상품 UI, ScriptableObject 상품 데이터, 튜토리얼, Red Dot, 월간 패스, 신화 상자 기능을 리팩토링 및 구현했습니다.
- 깡깡냥 프로젝트를 초기 생성부터 담당하며 Breadmore Core 기반 부트스트랩, 저장, UI/HUD, 데이터 테이블, 상점/IAP, 투사체/VFX 시스템을 구축했습니다.
- Firebase, GameAnalytics, Singular 등 외부 SDK 문서를 기반으로 이벤트 라우팅, 파라미터 정리, 빌드 설정, 보상 흐름을 클라이언트 기능과 연결했습니다.
- Crashlytics 지표를 활용해 crash-free users 95% 이상을 운영 목표로 관리했고, 하락 구간 발생 시 로그 보강과 후속 빌드 수정으로 회복하는 QA 사이클을 유지했습니다.

## 프로젝트별 이력서 문구

### 빠지냥

- 코어 게임만 있던 Unity 모바일 게임을 인수해 Lucky Pass, 게임플레이 기믹, 리더보드, 경쟁 콘텐츠, IAP/광고, SDK/분석 이벤트, 안정성 대응까지 라이브 클라이언트 기능을 확장했습니다.
- 시즌 리소스와 보상 테이블을 분리하고, 콘텐츠가 늘어난 뒤에는 Content Scheduler와 Resource Optimizer를 제작해 운영 작업을 구조화했습니다.
- Firebase Crashlytics를 활용해 crash-free users 지표를 추적하고, 원인이 불명확한 문제는 로그 보강과 반복 빌드로 재현 범위를 줄이며 수정했습니다.

### 장난EZ렁

- 기존 로비 코드를 인수해 VContainer 기반 프로젝트 컨벤션에 맞춰 상점, 상품 버튼, 튜토리얼, Red Dot, 월간 패스, 신화 상자 기능을 정리했습니다.
- 프리팹에 몰려 있던 구매, 표시, 가격, 보상, 매진 상태 로직을 데이터, 서비스, ViewModel, 공통 UI 컴포넌트로 분리했습니다.
- 이전 작업자의 기능을 유지하면서 프로젝트 아키텍처에 맞게 재배치해 이후 로비 기능을 같은 패턴으로 확장할 수 있게 했습니다.

### 깡깡냥

- 프로젝트 생성부터 Unity 클라이언트 구조, 게임플레이, UI/HUD, 데이터 테이블, 상점/IAP, 투사체/VFX 시스템을 직접 구축했습니다.
- 빠지냥에서 반복적으로 만들었던 저장, 보상, 상점, UI, IAP, 리소스 흐름을 Breadmore Core 기반 구조로 재구성했습니다.
- 모델/뷰 분리, 오브젝트 풀링, 공간 그리드, CSV 데이터 로딩, provider 기반 IAP 구조를 적용해 기능 확장과 유지보수를 고려한 기반을 만들었습니다.
