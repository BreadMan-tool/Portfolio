# Toy Commando Capture List

공개 페이지에는 모든 화면을 넣기보다 로비 구조가 보이는 화면만 4-6장 사용한다.

## Recommended Public Screens

- Shop main screen: General / Charge / Diamond / Legendary Gacha 탭 구조가 보이는 화면
- Product buttons: soft product, box product, random product가 한 화면에 보이는 상점 일부
- Legendary Gacha: pity, pickup, rate/info, draw button이 보이는 화면
- Monthly Pass: tier/benefit/daily reward가 보이는 화면
- Tutorial: highlight, toast, click guide가 보이는 화면
- Red Dot: 로비 탭이나 상점 탭에 red dot이 표시된 화면

## Good Short Videos

- 상점 탭 전환과 캐러셀 이동 8-12초
- 튜토리얼 highlight 후 버튼 클릭 8-12초
- Legendary Gacha 1회 또는 10회 연출 8-12초

## Avoid

- 실제 결제 계정, 영수증, transaction ID
- 내부 Jira/QA 텍스트
- 테스트 가격이나 미출시 SKU가 그대로 보이는 화면
- 작업자 이름, 브랜치명, 내부 코드 경로가 보이는 에디터 화면
